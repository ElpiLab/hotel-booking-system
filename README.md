# Hotel Booking System

A hotel booking system developed as part of the Database Technology module at FHNW.

The project focuses on relational database design and implementation, including
entity-relationship modelling, normalization, SQL and database operations.

## Current Scope

- Entity-Relationship Model
- Relational database design
- Database normalization
- SQL and database queries
- Integrity constraints
- PL/SQL procedures and triggers
- Indexing and query optimization
- Transactions and concurrency

## Technology

- Oracle Database
- Oracle SQL Developer Data Modeler
- SQL
- PL/SQL

## Status

Work in progress.

The project may be extended in the future with an API, business intelligence
components or other application layers.

## Context

Developed during the B.Sc. Business Information Technology program at
FHNW, Spring Semester 2026.
